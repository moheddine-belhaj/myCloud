# defaults

| File | What it does |
|------|--------------|
| `main.yml` | Default values: `vault_config_admin_user` (your login), `vault_config_kv_path` (`secret`), `vault_config_policies` (`admin`, `eso`, `snapshot`), k3s API address and kubectl context, and the ESO role settings (ServiceAccount name/namespace, audience, token TTL). |
